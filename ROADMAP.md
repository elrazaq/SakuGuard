# SakuGuard Development Roadmap

- [x] **Phase 0 — Project Foundation**: Gradle, Compose, Material 3, Hilt, Navigation skeleton, Design System, CI, Docs.
- [x] **Phase 1 — Core Database & Financial Engine**: Room entities, DAOs, deterministic `Long` balance & allocation engine, unit tests.
- [x] **Phase 2 — Wallet Management**: Wallet CRUD, opening balances, archival/restore, wallet detail, wallet summary.
- [x] **Phase 3 — Transaction Management**: Income, expense, transfer, categories, filters, search, edit/delete consistency.
- [x] **Phase 4 — Savings Goals & Protection**: Multi-wallet goal allocations, withdrawals, Standard / Protected / Strict Protection modes, lifecycle & history.
- [ ] **Phase 5 — Dashboard**: Total assets, free money, allocated/protected funds, monthly summary, privacy toggle.
- [ ] **Phase 6 — Budgeting**: Monthly, weekly, custom, one-time budgets, planned spending, 80%/100% threshold warnings.
- [ ] **Phase 7 — Reports**: Offline income/expense, category breakdown, cash flow, trends, filters.
- [ ] **Phase 8 — Backup & Restore**: `.saku` export/import (JSON + ZIP + AES-GCM + PBKDF2), merge & replace modes, schema versioning.
- [ ] **Phase 9 — Polish & Production**: Accessibility, dark mode QA, migration tests, app icon, splash screen, release build.
